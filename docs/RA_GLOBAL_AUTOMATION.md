# RA 우선 멀티모달 문서 자동화

2026-10-04 추가 작업임. 외부 HTML 공유 페이지는 `docs/SHARING.md`의 고정 작업 기록이며 실제 작성 프로그램은 로컬 실행함.

## 사용 순서

`app/ra_workflow_ui.py`의 공식 양식 기입, RA 변경 공식 기입, 해외영업·글로벌 문서에서 원자료를 첨부함. PDF/DOCX/HWP/HWPX/XLSX/TXT/CSV/TSV/PPTX와 PNG/JPEG를 같은 출처 형식으로 읽음. 이미지 자동 읽기는 기본 꺼져 있으며 설정한 이미지 지원 모델이 필요함. 모델이 없거나 호출에 실패하면 다른 유료 API·mock으로 대체하지 않음.

사진·스캔 자료의 실제 원문을 담당자가 전사해 등록하는 경로도 제공함. 원본 SHA·페이지·원문 위치와 전체 문맥을 보존함. 사진·스캔/OCR/전사문은 담당자가 원본과 대조한 조각만 작성 근거로 전달함. 보호·추출 제한 PDF는 OCR로 우회하지 않음. 보류된 파일이나 미확인 조각이 남으면 공식 기입 다운로드를 진행하지 않음.

직접 전사문을 수정하거나 원문 확인을 해제하면 이전 기입 결과를 무효화함. 사용자 전사는 실제 확인 기록일 뿐 의약품 사실·허가 상태·법적 적합성 인증은 아님.

## RA 변경 공식 기입

1. 원문 제품명·제형·함량과 변경 전/후 실제 자료를 별도로 지정함.
2. 정확한 같은 항목명을 비교하고 담당자가 확인한 차이 1~3개를 선택함.
3. 변경 사유는 실제 자료의 정확한 인용 또는 담당자가 실제 작성한 사유로 제공함. AI가 사유·승인을 추정하지 않음.
4. 사용한 행의 항목·변경 전·변경 후·사유를 모두 검수한 뒤 공식 PDF의 원래 3행에 기입함.
5. 저장 후 원위치·원본 보존을 독립 검수하고 PDF·출처 JSON·작업 패키지 ZIP을 받음.

사용하지 않은 행은 비워 두며 3행을 넘는 변경을 잘라내지 않음. 공식 양식의 선정 입력칸과 미등록칸, 서명·선택·첨부·최신 제출 요건을 구분함. 출력 통과를 변경 승인이나 법정 제출 완료로 표시하지 않음.

## 글로벌 업무

견적송장(Proforma Invoice), 상업송장(Commercial Invoice), 포장명세서(Packing List), 해외영업 활동보고를 대표 우선 업무로 구현함. 예제 양식은 프로젝트 제작 문서이며 회사·한국무역협회 공식 양식으로 표시하지 않음. 원본 SHA에 연결된 확인 매핑을 가진 사용자 양식도 같은 기입·검수 경로를 이용함.

원문 거래번호와 같은 거래의 정확한 항목·품목 행을 연결하고 수량·단가·금액·통화·중량을 보존함. 수량×단가, 총금액, 순중량≤총중량 관계가 틀리면 출력 전에 보류함. 환산·누락값 생성·첫 선택·서명·선적 상태 확정은 하지 않음. 사용 빈도 통계를 확보한 순위가 아니며 공식 정의와 대표 항목의 출처는 `docs/GLOBAL_WORKFLOWS.md`에 보존함.

## 평가의 구분

선정 원문 기입·합성 시험·mock 이미지 읽기 회귀와 실제 모델 추론/직원 업무 평가는 별도 기록함. 실제 RA AI 초안 성공과 직원 수정 비율·반려·재작업은 아직 미측정임. 이 문서의 구현 완료를 실제 회사 전수 호환·수정0%·통관/법정 제출 적합성으로 해석하지 않음.
