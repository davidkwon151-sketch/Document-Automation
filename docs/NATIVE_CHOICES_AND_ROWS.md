# 선택 목록과 반복 항목 검증

원본 양식의 선택값을 잘못 입력하거나 표의 일부 필수 칸을 빠뜨려 사람이 다시 수정하는 일을 줄이기 위한 보강임. 자동 회귀·실자료 구조 검증과 실제 AI 초안 품질·사용자 수정 비율은 따로 평가함.

## 작성 동작

- DOCX 드롭다운은 원본의 저장 값과 표시 문구를 구분함. 콤보는 원본이 허용하는 자유 입력을 유지함. 옵션·글꼴·주변 안내문·선택 속성을 저장 후 독립 대조함.
- XLSX 목록은 원본 XML에서 읽음. 명시된 인라인 목록, 범위, 정의 이름과 x14 확장의 지원 범위를 검사하며 원본 유효성 검사와 수식·스타일을 유지함. 물리적인 셀 XML이 없는 빈 칸도 원본에 선언된 제한 범위에서 처리함.
- 화면에는 미선택 항목을 먼저 표시함. 저장 코드와 표시 이름이 달라도 정확한 코드가 전달됨. 잘못 복원된 선택은 오류를 알리고 사용자가 직접 지우거나 다시 고르게 함.
- 직접 입력한 선택값·숫자·날짜와 일부만 채운 직접 입력 그룹은 모델 호출·자료 파싱 전에 검사함. 원자료에서 채울 항목은 초안 작성 후 다시 검사함.
- 초안 JSON에는 출처를 유지하고, 선택 컨트롤에 인쇄할 값에서만 유효한 끝 인용 ID를 분리함. 출처 존재만으로 허용하지 않는 선택값을 통과시키지 않음.
- 등록된 프로파일은 승인된 입력 위치만 유지하면서 현재 원본의 선택 제약을 복원함. 새로 발견한 입력칸을 승인 없이 추가하지 않음.
- 필수 원본 입력 위치를 매핑 행·직접 호출·캐시 저장에서 제외할 수 없음. 같은 값을 반복 표시하는 칸은 JSON 값을 재사용하되 필수 원위치를 남겨야 함. 실제 입력값·초안·원자료가 잘못 섞인 프로파일도 모델 메타데이터와 매핑 캐시에서 제거함.
- 실제 공개 양식의 배열 수식과 데이터테이블 수식은 원문 XML의 수식·속성·범위를 대조함. 파일을 다시 열 때 만들어지는 객체가 다르다는 이유로 보존된 수식을 오류로 처리하지 않음. 수식 텍스트·적용 범위·종류를 바꾼 출력은 차단함.

## 고정 반복 행의 완결성

`constraints.groups`의 `all_or_none`에 같은 행·구간의 항목을 선언함. 전부 빈 행은 선택 사항이면 유지하며, 하나라도 입력하면 선언한 `required_fields`를 모두 요구함. `required_fields`를 생략하면 그룹의 모든 항목을 요구함. 숫자 0도 입력한 값임.

```json
{
  "constraints": {
    "groups": [{
      "kind": "all_or_none",
      "fields": ["품목1", "수량1", "금액1", "비고1"],
      "required_fields": ["품목1", "수량1", "금액1"]
    }]
  }
}
```

입력칸 이름을 바꾸면 그룹 참조도 함께 바뀜. 일부만 매핑하거나 서로 다른 항목을 같은 값으로 합치는 모호한 매핑은 차단함. 확인 매핑 캐시는 `template-mapping-5`이며 개인정보·실제 답변·초안은 저장하지 않음. 이전 버전 캐시는 다시 확인해야 함.

## 검증 근거와 제한

2026-10-03 최종 전체 pytest는 **1,759개 통과·skip 1개·경고 2개·245.41초**임. mock 평가 15/15와 전문 업무 규칙 평가 24/24는 이전 대비 하락 없음. 실제 모델 평가는 아님.

최종 코드 동결 후 RA 원자료 4개·374쪽·124표·19개 선택 사실을 파싱하고 선택 기입 출력 11건·42쪽을 독립 검수함. 원문/출처 41/41와 수치 포함 필드 35/35가 보존됐으며 에리우스의 추출 제한 2사례는 보류함. 원본·manifest·프로필 13파일 및 관련 코드 12파일의 전후 SHA가 같음. 정상 17/17·변조 92/92 검출은 검사 코드의 SHA가 같은 앞선 평가를 명시적으로 재사용함. [최종 RA 요약](../outputs/ra-native-choice-final/summary.json)은 원문 복사 규칙 평가이며 이번 출력의 직접 시각 재검수는 수행하지 않음.

실제 공개 XLSX 4개는 KOTRA 수출상담회, 스마트공장 사업비, 대구경북첨단의료산업진흥재단 기술 신청, 한국성장금융 제출서식임. 목록 규칙 109개 중 104개를 해석함. 빈 선택칸은 각각 500·0(보호)·9·38개를 발견했고 한국성장금융의 미확인 칸 172개는 보류함. 기입 가능한 3개에서 대표 1칸씩 3/3 기입·독립 검수 통과, 원본 불변 4/4를 확인함. 목록 규칙 수나 발견한 칸 수를 전체 기입 성공 수로 표시하지 않음.

세부 지원 범위는 [DOCX](DOCX_CHOICES.md)와 [XLSX](XLSX_CHOICES.md)에 기록함. 실제 공개 XLSX의 선택 목록은 `outputs/native-choice-qa/report.json`, 전체 회귀와 RA 실자료 재검증의 통합 근거는 `outputs/native-choice-verification.json`에 기록함. 검사 분모는 목록 규칙 수·빈 입력칸 수·선택 출력 수를 구분함.

보호된 시트와 잠긴 콘텐츠, 연결 XML을 갱신해야 하는 Word 컨트롤, 누락된 목록 시트·지원하지 않는 동적 목록은 자동으로 기입하지 않음. 끝 행까지 선언된 Excel 목록은 탐색 한도를 표시하며 전 셀 검증으로 세지 않음. 동적 반복 행 생성, Word/Excel의 실제 렌더·계산 결과, 회사별 비공개 양식 전수 확인은 남은 범위임.

RA 검증에는 [EMA의 공식 제품정보](https://www.ema.europa.eu/en/medicines/human/EPAR/herzuma)와 [한미약품 제품 페이지](https://www.hanmi.co.kr/business/product/finder/detail-1245.hm?prodSeq=1245) 등 기존 인터넷 원본 스냅샷을 사용함. 회사 역할·관할·제품 제형·전체 인용·페이지·SHA를 대조하고 보호 제한 사례는 보류함. 원문을 정확히 옮기는 규칙 평가와 실제 LLM 작성 평가를 구분함. 원본 페이지를 재확인한 것만으로 모든 문서의 최신 허가·제출 요건을 인증하지 않음.

API 모델 응답과 실제 담당자의 최종 수정본을 확보하기 전에는 수정 비율 0%나 프로젝트 전체 완성을 선언하지 않음.

재현 명령:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest -q --junitxml=outputs/pytest-native-choices.xml
.\.venv\Scripts\python.exe -X utf8 -m evals.run --mode mock --baseline outputs/evaluation-value-rules.json --output outputs/evaluation-native-choices.json
.\.venv\Scripts\python.exe -X utf8 -m evals.domains --mode rules --baseline outputs/domain-value-rules.json --output outputs/domain-native-choices.json
```

RA의 실제 실행 명령·모드·코드/원본/출력 해시는 최종 요약의 `commands`와 `result_files`에 기록함. 권한 보류로 한국어 평가 CLI는 exit 1을 반환하며 예상 보류와 다른 실패를 구분함.
