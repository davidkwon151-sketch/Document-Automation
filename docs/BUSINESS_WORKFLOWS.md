# 해외영업·해외사업·정부지원·R&D 작성 보조

`agent.business.inspect_business_draft(draft, sources, profile=...)`는 첨부 원자료와 평면 문자열 초안을 대조함. `profile.domain='business_support'`, `profile.business_workflow`로 업무를 선택함. 거래 판단·지원 자격·법적 적합성·선정 가능성을 인증하지 않으며 체크리스트는 담당자의 추가 확인사항으로만 제공함.

| 업무 key | 작성 흐름 | 근거를 보존할 항목 |
|---|---|---|
| trade_sales | 견적·계약·발주·선적·통관·대금회수 | 상대/국가·품목·HS·통화·금액·Incoterms와 지정장소·납기·실적 증빙 |
| overseas_business | 시장·파트너 검토·프로젝트 계획·투자/계약·진행 보고 | 프로젝트 번호·국가·기준일·단계·계획/추정/실적·비용 범위 |
| government_grant | 공고·신청·선정·협약·집행·검수·정산·지급 | 공고/사업연도·신청기간·정부지원/기업부담·현금/현물·VAT·지급 증빙 |
| rd_project | 공고·접수·기관 승인·협약·수행·성과·정산 | 과제 번호·기관·연차·목표/실적·정부지원/기관부담 연구개발비·변경 협약 |

공식 자료 확인일: 2026-10-03. 다음 자료는 실제 업무 흐름의 참고 근거이며 개별 사업의 요건·비율·기간을 다른 사업에 적용하지 않음.

- [KOTRA 무역투자24 문의·상담](https://www.kotra.or.kr/subList/20000006014?targetId=e): 수출·해외투자·프로젝트 수주지원 관련 상담 경로를 확인함.
- [한국무역협회 외화입금 기반 실적증명 업무 도움말](https://membership.kita.net/cert/sec/requestHelp.do): 입금 증빙·계약서·계약 당사자·송금인/수취인 대조, 신청, 담당자 확인과 승인, 발급의 구분을 확인함. 모든 수출실적 증명 업무가 같은 절차라는 의미가 아님.
- [관세청 수출 통관](https://www2.customs.go.kr/kcs/cm/cntnts/cntntsView.do?cntntsId=818&mi=2820): 계약, 물품 확보, 신고·수리, 운송·적재 등 흐름과 정확한 신고 내역 대조를 확인함. AI가 HS 분류·통관 요건을 확정하지 않음.
- [수출바우처 사업안내](https://www.exportvoucher.com/portal/bizinfo/voucher_01), [정산가이드](https://www.exportvoucher.com/portal/board/boardList?bbs_id=9): KOTRA·중진공 운영 사업에서 기업부담과 국고를 구분하고 사업별 조건이 상이함을 확인함. [현재 공지 목록](https://www.exportvoucher.com/portal/board/boardList)의 2026년 모집·선정·검수 공지는 각각 다른 단계임. 과거 물류바우처의 지원 비율·VAT 조건을 현재 전체 사업의 조건으로 사용하지 않음.
- [창업진흥원 초기창업패키지](https://www.kised.or.kr/menu.es?mid=a10205020000): 공고, 신청·접수, 평가·협약, 사업비 지원의 구분과 사업계획·증빙 자료 경로를 확인함. 페이지의 예정 일정은 실제 최신 접수기간으로 확정하지 않음.
- [IRIS 2026년 4극3특 중부권 과학기술혁신지원사업 연구단 모집](https://www.iris.go.kr/contents/retrieveBsnsAncmView.do?ancmId=024139&ancmPrg=ancmIng): 2026-09-11 공고와 2026-10-12 접수 종료, 과제별 지원 기준·기관 승인·제출자료 확인 경로를 확인함. 이 공고의 지원 비율은 이 사업에 한정함. [IRIS 안내](https://www.iris.go.kr/main.do)의 설명처럼 실제 접수 가능 일정은 개별 공고문/신청 화면에서 재확인함.

검수와 제한

- 문장에 인용된 자료만 사용하며 과제·거래·공고 번호, 회사, 기간, 계획/실적, 금액 항목을 구분함. 같은 금액이 다른 과제·자부담·실적에 있어도 서로 근거가 되지 않음.
- 통화와 금액을 보존함. KRW 단위 표기·명백한 국가 통화 코드와 천/만/억 같은 자리 단위만 비교용으로 정규화하고 초안을 수정하지 않음. 환율 변환·합계·지원비율·정산액은 계산하지 않음. `$`만 있으면 통화를 추정하지 않고 경고함.
- Incoterms·지정장소, 명시 HS 코드·국가·납기/신청기간을 대조함. HS 코드의 구두점과 흔한 국가 이름 별칭을 정규화하지만 품목분류나 알려지지 않은 국가 번역을 자동 확정하지 않음.
- 승인·선정·보조금 수령·수출 완료·성과 달성의 긍정 상태를 인용 자료에서 대조함. 동일 식별자와 긍정/부정/예정 구분을 사용하여 문장 전체 문자열 일치만 요구하지 않음. 일반적인 모든 자연어·외국어 거래 문구의 의미 동등성을 완전히 판단한다는 주장은 하지 않음.
- 서명·계좌·수취인·거래 결정은 생성하지 않음. 해당 항목의 근거가 없으면 차단하고, 첨부 문서에서 확인했어도 사용자의 직접 입력 출처가 없으면 확인 경고를 제공함. 원본의 서명 이미지를 복제하거나 거래 승인 행위를 수행하지 않음.
- 고정 양식 셀·외국어 계약 문체를 변경하지 않음. API에는 외부 LLM·네트워크 요청이 없으며 반환 오류는 다운로드 전에 해결하고 경고는 담당자가 확인함.

반환은 `domain/workflow/blocking/issues/checks/additional_checks`임. `issues`는 `code/field/line/message/severity`이며 현재 초안·출처마다 다시 실행해야 함. 이 검수 통과는 최신 공고·법령 확인과 담당자의 거래/정산 검토를 대체하지 않음.
