# 의약품 RA 작성 보조와 원자료 검수

`agent.ra.inspect_ra_draft(draft, sources, profile=...)`는 신청·변경·임상시험·원료등록·제조품질·제조/수입·안전성 문서의 원자료 대조를 수행함. 의학적 판단, 허가 가능성 또는 법적 적합성을 인증하지 않음. 최신 법정 제출 요건과 서식은 담당자가 해당 민원·품목·제형에 맞춰 공식 원문에서 확인해야 함.

| 업무 key | 작성 보조 대상 | 담당자가 추가 확인할 사항 |
|---|---|---|
| product_approval | 품목허가·CTD | 품목·제형·함량·용법·효능, 신청 구분, CTD 원문 위치와 지역별 항목 |
| variation | 변경허가·신고 | 변경 전후 대비표, 변경 사유·자료 버전·제출 경로 |
| clinical_trial | IND 계획·변경 | 시험번호, 계획서 버전, 대상·용량·평가변수, 승인과 시험 완료 상태의 구분 |
| dmf | 원료의약품 등록·변경 | 원료·제조원·제조소·공정·규격·배치 및 등록 버전 |
| gmp | GMP·실태조사 대응 | 제조소·공정·기록·검증·시험 결과, 실태조사와 적합 판정 상태 |
| manufacturing_import | 제조·수입 신청 | 신청 주체·업무 구분·제조소, 직접 입력과 증명·첨부자료 |
| safety_management | RMP·안전성 자료 | 대상·기간·분모·이상사례, 위해성 구분과 원자료의 한계 |

위 항목은 추가 확인사항이며 법정 필수 자료 목록으로 자동 판정하지 않음. 체크리스트가 있다는 이유만으로 누락 오류를 만들지 않음.

확인한 공식 자료(2026-10-03)

- [ICH CTD](https://admin.ich.org/page/ctd): CTD는 5개 모듈로 구성되며 Module 1은 지역별이고 Module 2~5는 공통 구조임. 한국 신청 양식에 ICH 원문 전체를 동일하게 적용한다고 판단하지 않음.
- [MFDS 원료의약품 (변경)등록 및 연계심사 가이드라인](https://www.mfds.go.kr/law/board/boardDetail.do?brdId=data0011&menuKey=38&seq=15802): 공식 게시일 2025-12-26, 안내서-1109-06의 존재와 제목을 확인함. 개별 제품 적용 여부는 추가 확인 대상임.
- [MFDS 임상시험 계획(변경) 승인 보완사례집](https://www.mfds.go.kr/brd/m_1060/view.do?seq=15953): 공식 게시일 2026-09-17인 안내 자료를 확인함. 사례집이 모든 IND 제출 요건을 대신하지 않음.
- [MFDS 위해성 관리 계획 운영 등에 관한 규정](https://www.mfds.go.kr/brd/m_211/view.do?seq=14879): 제2025-10호(2025-02-28) 게시물을 확인함. 이후 개정과 품목별 적용은 접수 전에 다시 확인해야 함.
- [MFDS 고시·훈령·예규](https://www.mfds.go.kr/brd/m_207/list.do), [의약품안전나라](https://nedrug.mfds.go.kr/): 현행 규정·민원 및 품목 정보를 확인할 공식 경로임. 의약품안전나라는 동적 화면이므로 이번 자동 열람으로 개별 민원 상세·첨부 목록을 검증했다고 표시하지 않음.

검수 규칙

- 검수는 각 문장에 인용된 출처만 사용함. mg, µg/μg/mcg, %, mg/mL, mg/kg 등 양·단위와 시험/배치 문맥을 대조함. 마이크로 기호 표기만 정규화하며 mg↔µg와 같은 배수 환산이나 숫자 수정을 수행하지 않음.
- 시험/배치 번호, 명시 날짜, 투여 빈도와 경로를 대조함. 날짜 구분 순서가 모호하면 원자료 확인 경고를 제공하고 임의 해석하지 않음.
- 안전성·효능·승인·임상 완료·GMP 적합 주장은 인용 원문에 동일 근거 문구가 없으면 차단함. 의미가 같아 보이는 다른 표현도 자동 승인하지 않으므로 담당자가 원문을 확인해야 함.
- 임상 자료의 모든 의학적 의미, 문서 간 누락, 보편적인 제품명·시험 식별자 표기와 복잡한 용법을 정규식이 완전히 이해한다고 주장하지 않음. 이 검사 통과는 RA 담당자 검토를 대체하지 않음.
- 신청서 고정 셀, 코드·번호, 영어 CTD 원문에 한국어 개조식 문체를 강제하지 않음. API는 원문·초안을 변경하지 않으며 외부 모델·네트워크를 호출하지 않음.

반환에는 `domain`, `blocking`, `issues`, `checks`, `workflow`, `additional_checks`가 포함됨. 오류는 다운로드 전에 해결하고 경고는 담당자가 원자료와 확인함. `issues`는 `code/field/line/message/severity` 형식이며 검수 재실행 시 현재 초안·출처를 다시 대조해야 함.
