# RA 담당자용 가입 없는 작업실

## 사용하는 순서

1. 운영자가 발급한 담당자별 초대 링크로 접속함. 계정은 만들 필요가 없음. 확인한 원문 기입은 API 키 없이 사용하고, Gemini AI 작성·사진 읽기·재검수에는 본인의 Gemini API 키를 입력함.
2. 회사의 원본 양식 한 개와 기존 자료를 함께 업로드함. 양식은 DOCX, HWP/HWPX, XLSX, PDF이며 자료는 이 형식과 TXT/CSV/TSV/PPTX/PNG/JPEG를 지원함. 최대 12개 원자료, 요청 전체 10 MB임.
3. 입력 위치·작성 항목·제품·제형/함량·RA 업무를 확인함. 신청인·서명·동의·승인 값은 담당자가 직접 입력함. 등록 원본의 업무 분류·필수 조건·선택값은 유지함.
4. ‘저장하고 자동 기입 후보 찾기’로 항목별 원문과 출처를 확인함. 정확한 기존 항목은 ‘확인한 원문 기입’, 요약·새 문장 작성은 ‘실제 AI 작성·검수’를 사용함.
5. 누락·수치·출처·조건 오류를 보완함. 최종 확인 후 다운로드하면 원위치·양식 보존을 다시 검사하고 작성 문서와 출처 JSON을 ZIP으로 제공함. 오류를 숨기거나 빈 사실을 생성하지 않음.

사진·스캔은 실제 모델 자동 읽기 또는 전체 페이지 수동 전사를 사용함. 읽은 원문은 페이지·원본 SHA에 연결해 담당자가 확인해야 작성 근거가 됨. 자동 읽기 실패·부분 페이지·추출 제한 문서를 완료로 처리하지 않음. 영상·음성 직접 입력은 아직 지원하지 않음.

## 가입 없이 자료를 보호하는 방법

초대는 1회 입장, 발급 시 설정한 만료(기본 24시간, 최대 7일)를 가짐. 세션은 최대 24시간이며 초대 만료를 넘지 않음. 링크를 받은 사람은 같은 브라우저에서 ‘내 최근 작업’을 이어서 사용할 수 있음. 다른 담당자의 작업 ID로 조회·수정·다운로드할 수 없음.

링크 자체가 입장 권한이므로 지정 담당자에게만 전달함. 각 담당자에게 다른 링크를 발급함. 만료·기기 변경 시 운영자가 같은 초대 ID를 갱신하면 기존 작업공간을 유지하며 이전 링크·세션은 종료됨. 공개 화면에서는 초대를 발급하거나 갱신할 수 없음. 데이터 삭제·보관 기간의 조직 운영 정책은 별도로 정해야 함.

## 로컬 운영자 명령

프로젝트 루트에서 실행하며 결과 파일을 공개 Site에 넣지 않음.

```powershell
.venv/Scripts/python.exe -m app.guest_access --root data/external-users issue --label "RA 담당자 A" --site https://ra-document-workspace-20261004.sooyeon-jun-0389.chatgpt.site --output .runtime/ra-person-a.json
.venv/Scripts/python.exe -m app.guest_access --root data/external-users renew INVITE_ID --site https://ra-document-workspace-20261004.sooyeon-jun-0389.chatgpt.site --output .runtime/ra-person-a-renewed.json
.venv/Scripts/python.exe -m app.guest_access --root data/external-users revoke INVITE_ID
```

발급 파일의 `url`만 지정 담당자에게 전달함. 토큰은 주소의 fragment에 들어가 HTTP URL에 전송되지 않으며 입장 페이지가 주소에서 제거함. 서버에는 토큰 해시만, 브라우저에는 Secure·HttpOnly·SameSite 쿠키만 저장함. 모든 API는 게이트웨이 서명과 활성 세션을 다시 확인함.

## 현재 사용할 수 있는 범위와 미완료 범위

확인한 원문 자동 기입은 API 잔액 없이 동작함. 외부 작업실의 기본 AI 작성·사진 판독·재검수는 각 사용자의 Gemini API 키와 사용 한도로 처리하며, 키는 작업 기록에 저장하지 않음. Claude 구독자는 개인 MCP 연결을 선택할 수 있음. 실제 Gemini/Claude 모델 품질을 검증했다고 주장하지 않으며 모델 오류를 mock이나 원문 기입으로 자동 대체하지 않음.

처음 보는 양식은 실제 입력 위치를 분석할 수 있는 구조와 확인 매핑이 필요함. 빈칸 위치 없는 스캔 양식, 여러 조각으로 분리된 장문, 역할이 모호한 회사명 등은 보완이 필요할 수 있음. ‘모든 양식 완성’, ‘법정 제출 완료’, ‘담당자 수정 0%’는 검증되지 않음. 제출 적합성·제품 사실·첨부·서명은 담당자가 확인함.

현재 외부 운영은 이 PC와 터널이 켜져 있는 시험 배포임. 상시 운영 서버·실제 RA 직원 평가·실제 AI 모델 평가·사용자 수정률 측정은 별도의 완료 기준임.
