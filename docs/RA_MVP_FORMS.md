## 바로 사용할 수 있는 범위

- 별지 4는 제품명·성상·원료약품/분량·효능·용법 등 첫 쪽의 등록 텍스트 영역만 작성함. 신청인 성명/주소·제조소 명칭/소재지·업허가 번호는 사용자가 직접 입력함.
- 별지 20은 갱신 신청서 첫 쪽의 등록 텍스트 영역만 작성함. 신청인·영업소·업허가/품목허가 식별자는 직접 입력함. 기존 허가번호·갱신 상태를 제품 설명서에서 추정하지 않음.
- Eurofins는 회사·시료 제출자·연락 이메일을 직접 입력하고 제품명·시료 관련 메모만 명확한 근거가 있을 때 작성함. 제품명 참고 복사는 실제 시료의 동일성·시료 발송·제조·공급 관계나 시험 요청 완료를 증명하지 않음.
- 별지 8은 제품명과 첫 변경 행의 변경 항목·변경 전·변경 후·사유를 원자료 기반 항목으로 등록함. 신청인·제조소·전화번호·품목허가번호는 직접 입력함. 기본 데모는 제품명만 작성하고 다른 9칸은 비워 둠. 실제 변경 이력·전후 사항·사유가 있는 근거를 받기 전에는 단일 제품 설명서로 이를 추정하지 않음.

- 기존 별지 23 첫 쪽 설정은 `application`/`clinical_trial`이며 19칸을 유지함. 신청인·원개발사·제조원은 직접 입력함. 데모는 제품명 원문을 `시험약 제품명`에만 복사하며 국내 허가 여부·실제 임상시험·승인·변경 이력을 만들지 않음. 해당 첫 쪽 설정의 뒤쪽은 작성하지 않으며 새 앞·뒤쪽 설정의 목적·투여 방법 2칸과 구분함.
- 별지 32는 `report`/`safety_management`이며 첫 쪽 14칸을 재사용함. 승인일·정기보고 차수·승인받은 자·자료 마감·제출일은 직접 입력하며 원본의 날짜/정수 검사를 유지함. 데모는 `제품명 성분명`에 제품명만 넣고 성분명을 추가하지 않음. 임상시험 제목·대상자 수·안전성·위해성·결론과 뒷쪽 DSUR 세부표는 해당 시험 근거가 없으면 비워 둠.

등록 프로파일의 `required`는 해당 등록 칸의 검사 상태임. 전체 법정·기관 제출 필수 요건을 확정한 목록이 아니며, 미등록 선택·서명·날짜·첨부자료·수수료·접수 절차는 제출 전에 담당자가 원본 안내와 대조해야 함. 기본 결과와 데모는 실제 제출용 완성본으로 표시하지 않음.

## 원본과 시험 원자료

법정 양식은 [별지 4의 공식 원본 페이지](https://www.law.go.kr/LSW/lsBylInfoP.do?bylSeq=18000713&lsiSeq=284019&efYd=20260305&directYn=Y), [별지 20의 공식 원본 페이지](https://law.go.kr/LSW/lsBylInfoP.do?bylSeq=18000749&lsiSeq=284019&efYd=20260305), [별지 8의 공식 원본 페이지](https://www.law.go.kr/LSW/lsBylInfoP.do?bylSeq=18000723&lsiSeq=284019&efYd=20260305&directYn=Y)를 통해 확보한 PDF 스냅샷임. 본문 시행일 2026-03-05와 인쇄된 서식 개정일(별지 4·8: 2025-02-21, 별지 20: 2023-10-25)을 구분함. 이후 개정·현재 접수용 최신성·법적 적합성은 확인하지 않음. Eurofins는 [공식 공개 시료 제출 PDF](https://cdnmedia.eurofins.com/european-east/media/2854407/ebpt-sweden-sample-submission-form_ifyllbar.pdf)를 사용하며 확실한 개정일은 확인하지 못함.

기본 법정 데모는 [한미 공식 설명서](https://common.hanmi.co.kr/upfile/ces/product/40bba798-dedc-4ec2-8768-201a152df463.pdf)의 75mg 선택 원문을 사용함. 회사는 문서 발행사로 확인했으며 제조원·신청인으로 자동 변환하지 않음. [ra_korean_sources.json](../evals/ra_korean_sources.json)의 `ra-kr-hanmiflu-75`에서 별지 4·20은 `제품명`, `저장방법 및 유효기간`만 선택하고 별지 8은 `제품명`만 선택함. 성상에는 원문 줄바꿈이 있고 다른 장문에도 넘침이 있어 기본 데모에서 제외함. `한미플루 75mg`은 공통 설명서의 75mg 본문 전체 라벨이며 법정 허가 제품명 확정은 아님.

Eurofins 기본 데모는 [EMA Benepali 제품정보](https://www.ema.europa.eu/en/documents/product-information/benepali-epar-product-information_en.pdf)의 **25mg 프리필드시린지** 제품명 전체를 사용함. [ra_public_sources.json](../evals/ra_public_sources.json)의 `ra-public-benepali`에서 `제품명`만 선택함. EU 판매허가권자 역할은 국내 신청인·제조원·실제 시험 의뢰인으로 추론하지 않음. 개인정보·서명·동의의 가짜 QA 예시값을 MVP 카탈로그에 저장하지 않음.

신규 임상/안전성 원본의 공식 서식명·용도·인쇄 버전·미등록 뒷쪽과 시험 범위는 [RA_CLINICAL_SAFETY_FORMS.md](RA_CLINICAL_SAFETY_FORMS.md)에 기록함. `demo_field_map`은 별지23 `시험약 제품명`과 별지32 `제품명 성분명`을 기존 원자료 `제품명` 하나에 연결함. 원문·출처 ID·문서 SHA·원페이지·발행사 역할은 그대로 유지함.

## 실행 모드와 출력 조건

오프라인 데모는 이미 확보한 공식 공개 원문을 선택 칸에 복사하는 규칙 실행임. 실제 LLM 생성 평가나 사람의 사용 KPI가 아니며 API 설정 실패를 데모 성공으로 대체하지 않음. 실작성은 API 설정·실제 모델 응답이 필요하고 사용자 직접 정보와 원자료를 구분함.

기본 데모의 선정 8칸은 별첨 없이 전체 원문을 저장하고 원본 페이지 수를 유지함. 다른 긴 원문은 기본적으로 넘침을 차단함. 법정 정적 PDF에 사용자가 별첨을 명시 허용한 경우에만 근거 기반 본문 전체와 출처를 별첨으로 보존할 수 있으며 직접 입력·선택·서명은 별첨으로 대체하지 않음. Eurofins AcroForm의 직접 입력칸을 정적 PDF 별첨 정책으로 우회하지 않음.

PDF 값·AP·원위치·원본 비작성 영역 검수와 PDFium 표시 확인을 수행한 기존 기능을 재사용함. 별도 native checker의 모호한 표시 경고는 그대로 유지하며 실제 Acrobat 재편집·전자 제출·전체 배치 보장으로 표시하지 않음.

.venv\Scripts\python.exe -X utf8 -m pytest -q tests/test_ra_mvp_catalog.py

기존 첫 쪽 6설정 카탈로그 시험은 SHA 바인딩·원문 quote·등록 범위·선정 원문의 실제 기입/독립 검수·비선택 값 보존·잘못된 SHA의 기존 파일 보존을 대조함. 제8호 추가 회귀는 실제 원문 제품명만 기입하고 변경 전후·사유·신청인 정보가 비어 있는지 검사함. 원본/프로파일 SHA 변조·직접 입력 권한의 원자료 항목 변경·등록 항목 누락을 차단하며 기존 UI에 새 기록이 자동 표시되는지 확인함. 후속8설정 시험과 새4칸은 RA_SECOND_PAGE.md·VALIDATION.md의 최신 증거에 연결함. 카탈로그 최상위 확인 날짜/범위는 최초6설정의 수집 시점 메타데이터이며 최신 테스트 실행 시각이나 제출처 최신성 인증이 아님. 전체 RA 수집·전 항목 허가 신청 인증은 MVP 범위에 포함하지 않음.

이번 임상/안전성 추가 집중 시험은 카탈로그 35개가 통과함. 실제 원문 제품명 2칸과 별도의 가짜 위치 QA 33칸을 구분하여 기입·독립 검수함. 원본 4쪽·원문 데모 4쪽·가짜 위치 QA 4쪽, 총 12개 PNG를 직접 시각 확인했으며 새 입력의 잘림·겹침을 발견하지 못함. [QA 기록](../outputs/ra-clinical-safety/qa.json)과 [공식 응답 대조](../outputs/ra-clinical-safety/official-version-observation.json)는 실제 LLM/실사용 KPI 평가와 별도임. 이전 전체 pytest 결과와 이번 집중 시험의 분모는 혼합하지 않음.
