# 기획·재무·일상 기안·제조 품질 작성 보조

`agent.office.inspect_office_draft`는 원자료 근거 확인에 집중함. `profile.domain='office_finance'`, `profile.office_workflow`로 업무를 선택하며 반환은 `domain/workflow/blocking/issues/checks/additional_checks`임. 초안 변경·합계·환율·자동 투자추천·법정 적합성 인증을 수행하지 않음.

| key | 지원 문서 | 추가 확인사항 |
|---|---|---|
| office_planning | 전략·예산·경영계획·실적 보고 | 회사/부서·목표·계획/전망/실적·의사결정 요청·예산/집행·기준일 |
| financial_report | 재무·금융·투자 검토 | 원공시/정정·연결/별도·기간·잠정/감사·통화/단위·매출/이익·수익/위험 |
| daily_approval | 업무보고·구매·출장·비용품의 | 목적·견적/예산·일정·근거·결재 요청/완료·집행/정산·직접 입력 |
| industrial_quality | 제조 품질·개선·CAPA·납품 | 제품/로트·시험번호·규격·계획/검사실적·부적합·시정조치/효과 확인 |

공식 자료 확인(2026-10-03)

- [금융감독원 DART 정기공시 항목별 검색 안내](https://dart.fss.or.kr/guide/main.jsp?menu=410): 특정 회사의 사업·반기·분기 보고서와 원공시 전체를 확인할 수 있는 경로임. AI 검수는 공시 의무 충족을 인증하지 않음.
- [삼성물산 감사·검토 재무정보](https://www.samsungcnt.com/eng/ir/financial-info/audited-report.do): 2026년 별도/연결 및 분기 보고서 구분을 확인함. 개별 PDF 다운로드는 웹 도구의 content-type 제한으로 실패했으므로 원본 전체 검증 완료라고 표시하지 않음.
- [삼성전자 2026년 2분기 잠정실적 공식 공시](https://www.samsung.com/global/ir/reports-disclosures/public-disclosure-view.84695/): 2026-07-07 발표가 연결 추정치이며 외부감사 완료 전 안내와 미래 전망의 한계를 명시함을 확인함. 이 자료를 확정 감사 실적으로 바꾸지 않는 검수 원칙에 참고함. 발표 숫자를 다른 기업이나 기간의 자료로 사용하지 않음.
- [행정안전부 2025 행정업무운영 편람](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000012&nttId=122878): 2026-01-02 게시된 2025 편람과 PDF/HWPX 첨부를 확인함. 참고 문서일 뿐 민간기업의 실제 결재선·비공개 양식을 대신하지 않음. [경기도교육청 공문서·보고서 교육자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030111/BBS_202503100435531470.pdf)는 기안·검토·결재 흐름의 과거 공개 교육자료로만 취급함.
- [국가기술표준원 KOLAS 시험기관 안내](https://www.knab.go.kr/en/Testing_Lab.do), [인정 과정 안내](https://www.knab.go.kr/en/Accreditation_Process.do): 시험 범위·단위·원문 기록·부적합과 시정조치·확인/인정의 구분을 참고함. 페이지의 법령·요금·기간을 현행 법정 기준으로 인증하거나 모든 제조 품질 절차에 적용하지 않음.

검수 규칙과 제한

- 인용된 자료의 같은 항목·회사·과제/시험/로트·기간·연결/별도·계획/전망/실적을 대조함. 원/천원/백만원은 비교에만 동일 원 단위로 정규화하고 원문 표기를 수정하지 않음. 다른 통화의 같은 숫자는 같다고 보지 않음.
- %, %p, bp를 구분하고 환산하여 통과시키지 않음. 동일 단위의 bp/bps 표기만 정규화함. 매출·영업이익·순이익, 예산·집행, 검사 계획·결과는 다른 항목임.
- 승인 요청을 승인 완료로, 전망·잠정·계획을 확정 실적이나 검사 완료로 바꾸지 않음. 원금·수익 보장 주장이 근거 없으면 차단하고 인용 근거가 있어도 조건·상대·기간·위험 확인 경고를 제공함. AI가 그 보장을 승인하는 의미가 아님.
- 체크리스트는 참고 확인사항이며 없다는 이유만으로 법정 누락 오류를 만들지 않음. 비공개 회사의 내부 양식을 전수 확보했다고 주장하지 않음.
- 명시된 항목과 표지·동일 식별자·단위·긍정/부정 상태를 대조하는 결정론적 검사임. 모든 회계 의미·문서 간 누락·회계정책 변경·품질 판정과 시험 단위를 자동 이해한다고 주장하지 않음. 정정 공시/감사 의견, 시험 범위와 사용자 직접 결재는 담당자가 별도로 확인함.
- 검수는 원문과 초안을 변경하지 않고 고정 양식 셀·외국어의 한국어 문체를 강제하지 않음. 네트워크/LLM 요청이 없으며 현재 초안·출처마다 재실행해야 함. 오류는 최종 출력 전에 해결하고 경고는 원자료와 확인함.
