## 시간 추정의 분모

남은 **구현·연결·집중 검수 30~90분**을 예상함. 서비스/UI 담당이 병렬 작업 중이라는 전제에서 마지막 연결·오류 수정 15~45분, 통합/전체 회귀와 실행 확인 15~45분 정도임. 새 중대 결함이 발견되면 이 범위를 갱신해야 하며 확정 마감 보장이 아님. 관찰 시각 이후 파일·시험이 추가되면 단계별 근거를 새 시각으로 다시 기록함.

API 키를 받거나 외부 서비스를 기다리는 시간은 위 구현 시간에 더하지 않음. API가 없으면 명시적 오프라인 데모와 mock 기반 어댑터 시험까지 검증하고 실모델 평가 미실시를 표시함. 데모 통과를 LLM 실작성 평가 통과로 바꾸지 않음. 실제 사용자 수정 시간·수정 비율·상사 반려 KPI는 아직 관측 0건이며 소프트웨어 시험과 합산하지 않음.

이전 **10~24시간**은 3~5명이 20~30개 실제 문서를 사용하는 파일럿 범위로, 이번 대표 3종 로컬 MVP의 남은 구현 시간과 다름. 파일럿의 사람 사용·피드백·실모델 품질 검증을 이번 데모 완료만으로 끝난 것으로 보지 않음.
