# RA 임상·안전성 양식의 앞·뒤쪽 작성

2026-10-04 후속 확장에서는 기존 6개 공개 원본을 유지하고 별지 23호·32호의 앞·뒤쪽 작성 설정을 추가함. 메뉴는 8개 설정이며 고유 원본은 6개임. 기존 80개 입력 위치에 뒤쪽 4개를 추가하여 고유 입력 위치 84개(원자료 기반 53개, 직접 입력 31개)를 지원함. 중복 설정까지 합산한 등록 작업 수 117개를 새 입력 위치 수로 표시하지 않음.

| 작성 설정 | 추가한 원본 2쪽 입력 위치 | 필요한 원자료 |
| --- | --- | --- |
| 임상시험계획 승인(변경승인) 신청서(앞·뒤쪽 작성) | 임상시험 목적, 투여 방법 | 해당 제품·시험번호·절을 확인할 수 있는 임상시험계획서 |
| 정기 최신 안전성정보 보고서(앞·뒤쪽 작성) | 서론, 일련 목록과 요약표의 데이터 | 보고서번호·보고기간·제품·해당 절을 확인할 수 있는 DSUR 원자료 |

작성 전에 새 설정을 선택함. 기존 첫 쪽 설정과 원본을 덮어쓰지 않으며, 나머지 미등록 입력·선택·서명·첨부자료를 자동 완성한 것으로 표시하지 않음. 공개 제품 설명서의 제품명 복사 데모는 뒤쪽 임상·안전성 내용을 생성하지 않음.

## 원자료 연결과 검수

첨부 파일의 실제 바이트 SHA를 파싱 전후 대조하고 문단·페이지와 정확한 인용 범위를 보존함. 새 항목은 원래 제목·시험번호 또는 보고기간·절·제품이 같은 원문 블록에서 확인되어야 함. PDF는 원페이지를, DOCX는 실제 문단 위치를 사용하며 DOCX에 PDF 페이지를 만들어 넣지 않음. 파일명·목차·작성 가이드·분류 태그만으로 자격을 승인하지 않음.

양식의 제품명 칸으로부터 제품을 연결할 때도 실제 원자료의 정확한 제품명 인용이 필요함. 지시·직접 입력·불명확한 OCR·미등록 출처로 제품을 확정하지 않음. 원문 절을 확인한 것과 임상적 판단·법적 제출 적합성을 별도로 구분함.

등록 문서 종류·근거 범위·원본 항목명은 입력칸 ID에 묶어 매핑 캐시와 의미 검수 지문에 보존함. 서로 다른 절을 같은 값 이름으로 합치거나 검수 뒤 규칙을 바꾸어 이전 출력 결과를 재사용하지 않음. 좁은 칸의 넘침은 차단하며 별첨은 사용자가 명시적으로 허용한 경우에만 제공함.

## 재현 자료와 평가 범위

공개 원자료는 ClinicalTrials.gov의 NCT04162470 프로토콜임. 전체 원본은 68쪽이며 SHA는 `52c3066161ceee95cf4ecfea4656a81c36260bfcdb8e645ee669c8c9694d8007`임. 최초 선정 8·17·31쪽의 발췌 파일과 원페이지·바이트/콘텐츠 스트림 SHA·파서 문맥을 보관함. 후속 시험은 전체68쪽을 실제 파싱하고 선정절의 mock 작성→공식PDF 저장→독립 검수도 확인함. 68쪽 전체 파싱과 선정절 의미/기입 검증을 구분하며 모든 문장·절·임상 판단의 검증으로 집계하지 않음.

시험 목적과 투여 방법의 실제 공개 절, 목차의 제외, 다른 시험·제품·보고기간, 분류 태그 우회, 원자료 SHA 변경과 누락을 검사함. 실제 작성 파이프라인 시험의 LLM 응답은 mock임. DSUR 긍정 사례는 합성 시험자료이며 완성된 실제 DSUR 원자료의 검증과 구분함. 실제 모델 초안의 정확도·직원 수정률·상사 반려·작업 시간 KPI는 별도 평가가 필요함.

전체 회귀·독립 출력 검수의 최신 결과는 [검증 기록](VALIDATION.md)에 기록함. 초기 3종 MVP와 이후 단계의 숫자는 각 시점의 기록으로 유지함.
