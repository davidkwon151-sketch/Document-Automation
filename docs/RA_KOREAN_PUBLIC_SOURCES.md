# 한국어 공개 제품 설명서 검증 원자료

2026-10-03 KST에 공식 제품 페이지와 실제 다운로드 링크를 관찰한 한국어 PDF 스냅샷을 수집함. `evals/ra_korean_sources.json`의 평가 대상은 **회사 역할 2개, PDF 2개, 전체 5쪽, 선택 원문 11개**임. 모델 학습과 실제 LLM 평가는 수행하지 않았으며 국내 허가 현황·최신 개정·법정 제출 적합성은 별도 미검증임.

한미 설명서는 [한미약품 공식 제품 페이지](https://www.hanmi.co.kr/business/product/finder/detail-1245.hm?prodSeq=1245)의 `제품설명서 다운로드` 링크에서 확보함. [공식 원본 PDF](https://common.hanmi.co.kr/upfile/ces/product/40bba798-dedc-4ec2-8768-201a152df463.pdf)의 30mg·45mg·75mg 공통 설명서에서 75mg 본문 라벨, 해당 전체 성분 문단·성상, 밀봉 보관 조건, 성인/13세 이상 청소년의 감염 **치료** 용법 문단을 선택함. 예방 용법, 소아 체중별 표, 신장애 조절 용량은 혼합하지 않음.

한미의 `product_variant`는 본문에서 자동 원문 대조가 가능한 완전한 **strength 라벨** `한미플루 75mg`임. 상단 그래픽의 캡슐 제품 제목은 1쪽 좌측 상단 이미지로 확인해 `visual_full_title`에 별도 기록했으며 자동 인용 일치율의 분모에 넣지 않음. 이 라벨을 의약품안전나라의 법정 허가 제품명으로 확정하지 않음. PDF 2쪽의 제품문의처와 공식 게시 도메인으로 발행사를 확인했으며 제조원·판매원 역할을 추정하지 않음. 숫자로 된 사용기간은 원문에 없으므로 생성하지 않음.

에리우스 설명서는 [한국오가논 공식 제품 목록](https://www.organon.com/korea/home/)의 `에리우스®정 (데스로라타딘)` 링크에서 확보함. 원래 관찰한 링크의 비 ASCII 문자를 URL percent-encoding으로 보존했으며 파일 경로를 추정하거나 교체하지 않음. 제품명 전체, 1정의 전체 성분 문단, 성상, 효능·효과 전체 항목, 성인/12세 이상 소아의 전체 용법 문단, 보관·포장 표기 사용기한을 선택함. 약 106mg인 정제 전체 질량과 5mg인 유효성분 함량을 구분함.

에리우스 PDF 3쪽에는 `수입자`와 `한국엠에스디(주)`가 연속하여 인쇄되어 있음. 공식 웹 게시사인 한국오가논과 이 과거 인쇄 수입자를 별도 기록함. 2021년 작성 자료의 역할·제품 정보가 현재도 같다고 확정하지 않음. 사용기한은 외부포장에 표기한다고만 적혀 있으므로 숫자로 된 유효기간을 추가하지 않음. 원본은 암호 제공 없이 일반 공개 열람이 가능하지만 PDF의 `EXTRACT` 권한이 제한되어 있음. 따라서 자동 추출·OCR·양식 교차평가는 보류함. 암호를 입력하거나 보호를 해제하지 않았고 원본을 재저장하지 않음.

## 원자료 보존 및 확인 범위

- 원본은 `data/ra_public_validation/kr/`에 보관하며 원본별 `.source.json`에 공식 페이지·관찰한 URL·SHA-256·크기·실제 페이지·회사 역할·개정일·선택 범위를 기록함.
- 원문 `value`와 `exact_quote`는 선택 문단 전체를 보존하며 공백만 정규화해 실제 페이지 문자열과 대조함. 함량 단위·정제/캡슐 분모·연령·치료/예방 역할을 보존함. 부족한 신청인·허가번호·서명·사용기간을 채우지 않음.
- 수집 시점 독립 pypdf 판독으로 11/11개 선택 원문, 회사명·역할 문구, 개정일을 대조함. PDFium으로 평가 대상의 전체 5쪽을 렌더링하고 선택 문단·회사 역할·표와 제목을 이미지로 확인함. 이 과거 관찰 기록을 에리우스의 자동 추출 권한이나 현재 운영 평가 성공으로 해석하지 않음.
- **한미 운영 파서 재검증은 선택 원문 5/5개 보존과 원본 SHA 불변을 확인해 통과함.** 초기 2단 편집의 열간 혼합 문제를 수정한 결과임. [재검증 결과](../outputs/ra-real-source-korean.json)의 한미 사례는 법정 양식 2종에 5개 사실씩 기입해 2/2개가 통과함. 이는 원문 복사·규칙 검수 결과이며 실제 모델 평가가 아님.
- **에리우스는 `EXTRACT` 권한 제한으로 운영 파서와 교차평가를 보류함.** 일반 열람 가능 여부와 자동 추출 허용을 구분하며, 보호 문서는 `protected_document`로 차단함. 에리우스의 법정 양식 2종 사례는 미통과/보류로 기록하고 성공 건수에 포함하지 않음.
- 직전 한국어 교차평가는 선택 사례 4개 중 한미 2개 통과, 에리우스 2개 보호 보류임. 이후 [입력 항목 유형 반영 재실행](../outputs/ra-real-source-typed-korean.json)도 2/4개 통과·에리우스 2개 보호 보류였으나 새 출력의 시각 확인은 수행하지 않음. 직전 전체 프로젝트 회귀는 [pytest XML](../outputs/pytest-ra-real-sources-final.xml)의 1,258 passed·1 skipped·1 warning, 172.62초임. 이번 RA 조건 검수 반영 후 전체 회귀는 대기 중이며 집중 185개 통과와 구분함. skip 1개는 에리우스 자동 원문 대조 보류이며 보호 차단 자체의 별도 테스트는 통과함. 세부 분모와 실행 시점은 [실제 원자료 검증 보고서](RA_REAL_SOURCE_VALIDATION.md)에 기록함.
- 긴 성분·용법은 잘라내지 않고 별첨 또는 넘침 차단으로 검증해야 함. 이 자료 수집은 실제 양식 전항목 작성 완료·신약 허가 적합성 인증이 아님.
- 원본 7개를 확보했지만 평가 분모는 위 2개임. 나머지 5개를 성공 사례로 세지 않음. 원본은 Git 제외 대상으로 보관하며 재배포 권한은 확인하지 않았음.

## 이번 운영 RA 조건 검수

공통 RA 검수는 성상 문구가 실제로 인용된 자료에 있는지 확인하며 같은 임상 문장과 명시 연결된 후속 문장의 적용 조건·의사 판단·증량 조건 누락을 차단함. 본문이나 임의 항목명으로 작성한 임상 문장 및 사용자가 확인한 프로파일 `label`이 성상·용법용량인 입력칸에도 적용함. 원문의 모든 문장을 복사하도록 요구하지 않으며 명확한 초기용량 scalar 칸과 조건을 유지한 간결한 요약은 허용함. 약품명·정답 evaluator 메타데이터에 의존하지 않고 원문 숫자·단위·문체를 자동 교정하지 않음.

검색 근거의 주변 문맥은 M1이 읽은 같은 블록의 `context_text`와 인용 조각의 `context_start/context_end`로 연결함. 정확한 원문 범위가 `text`와 일치할 때만 연결 조건 검사에 사용하고, 잘못된 범위는 `ra_context_invalid` 오류로 차단함. 수치·성상 사실의 근거를 인용 조각 밖으로 확대하지 않음. 이번 실제 M1→검색 조각 회귀의 PDF 표본은 EMA Benepali·Keppra 2종이며 한국어 설명서 전체의 모든 조건에 대한 검출률로 치환하지 않음.

[이번 운영 변조 평가](../outputs/ra-public-adversarial-operating.json)는 실제 EMA 3개 자료·14개 사실에서 정상 17/17개와 선정 변조 92/92개를 확인함. 계층별 검출은 generic 65/92·RA 92/92·정답 비교 92/92, 검사 예외 0개, 원본 SHA 불변임. 직전 실행의 RA 88/92·generic+RA 합집합 89/92·정답 비교만 검출한 3개는 [이전 기록](../outputs/ra-public-adversarial-final.json)에 남아 있으며 이번 수정 후 잔여 사례를 뜻하지 않음. 해당 실행의 RA SHA-256은 `bc7aa2d6e9237dccc4e9cad5d225c5b09bdc4102751aabcc0c90b42d460c98d0`임.

연결 조건 검사 범위는 동일 원문 문장과 최대 3개의 명시 후속 문장임. 다른 페이지·원거리 문단의 연결, 의미가 같은 번역·요약, 규칙이 인식하지 못한 한국어·영어 임상 조건은 추가 의미 검수와 담당자 확인 대상임. 선정 변조셋 결과는 한국어 제품 설명서 전체의 정확도 인증이나 법정 제출 적합성 인증이 아님. 이번 평가도 네트워크·모델 요청 0회이며 실제 LLM 응답·사람 수정률 등 업무 KPI는 여전히 미측정임. 이전 원본 5쪽 이미지 관찰과 직전 출력 42쪽 렌더·19쪽 직접 확인을 이번 검수의 새 시각 확인으로 세지 않음.

## 재현

공유 평가기의 지원 범위 안에서 다음 명령을 사용함. 한미의 재검증 통과와 에리우스의 권한 제한 보류를 구분하고, 에리우스를 평가 모수에서 제외해 성공으로 바꾸지 않음.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m evals.ra_public --manifest evals/ra_korean_sources.json --mode rules --check-parser --profile ra_law_form_4_pdf --profile ra_law_form_20_pdf --output outputs/ra-real-source-korean.json --artifact-dir outputs/ra-real-source-round/korean
```

위 명령의 종료 코드 1은 에리우스 2개 보호 보류를 포함한 선택 사례 4개가 전부 통과하지 않았음을 나타냄. 보호를 우회하거나 에리우스를 제외한 값을 전체 성공률로 표시하지 않음. `rules`는 사람이 대조한 원문을 복사하는 검증임. 실제 모델 정확도나 사람 수정률을 의미하지 않음. [한국어 live 실행 기록](../outputs/ra-real-source-korean-live.json)은 API 키 미설정으로 실제 응답 0개·모델 평가 0개임. 설정 실패를 mock 성공으로 바꾸지 않음.
