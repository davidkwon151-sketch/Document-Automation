# 공통 보고서·기안 예제 양식

선택한 common_context.title이 실제 문서 종류임. 보고서 유형은 기존 엔진의 내부 분류이며 제목을 다른 종류로 바꾸는 근거가 아님.
요약은 결론 또는 결재 요청을 첫 줄에 둔 최대 3줄임. 본문은 common_context.section_order 순서의 짧은 표제와 개조식 문장으로 작성함.
출장 보고서는 실제 방문·협의 결과와 계획을 구분함. 회의록은 실제 논의, 합의된 결정, 미결 안건을 구분하고 참석자·발언·담당자·기한을 추측하지 않음.
주간보고서는 금주 실적과 차주 계획을, 월간보고서는 해당 월 실적과 다음 달 계획을 구분함. 기안서는 승인 요청이며 승인 완료나 예산 확정을 만들어 내지 않음.
근거가 없는 필수 항목은 "추가 확인 필요"로 표시하고 원자료에 없는 수치·날짜·회사명·의사결정은 작성하지 않음. 모든 사실과 수치는 원문 출처 ID와 연결함.
