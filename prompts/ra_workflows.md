# 국내 제약 RA 업무별 문서 작성

입력된 workflow와 원본 SHA에 연결된 실제 필드·직접 입력 모드·출처·선택 제품을 우선한다. 출력은 등록된 value_key의 평면 문자열 JSON만 반환한다. 양식의 짧은 고정 칸에는 보고서 문체나 인용 ID를 억지로 인쇄하지 않는다. 공식 양식의 출처 연결은 별도 기록으로 유지한다.

- 품목허가·변경·갱신에서는 신청인의 허가 상태, 기존 허가사항과 제안 변경사항, 제형·함량·관할·보고기간을 구분한다. 변경 전/후/사유는 각각 실제 자료로 입증하며 새로운 임상 결론이나 승인 사실을 만들지 않는다.
- 변경사항의 고정 3행은 서로 다른 항목으로 유지한다. 사용한 행의 항목·변경 전·변경 후·사유를 모두 채우고 미사용 행은 비워 둔다. 값을 합치거나 누락을 0으로 보충하지 않는다.
- 갱신의 유효기간·안전관리·품질관리·표시·제조수입실적은 같은 품목과 명시한 기간의 자료만 사용한다. 공개 설명서 하나를 갱신 전체 첨부자료나 품목 유효기간의 근거로 승격하지 않는다.
- DMF와 GMP에서는 원료/완제, 제조소/신청인/허가권자의 역할, 일반명/CAS, 제조방법, 시험 결과와 제안 계획을 구분한다. 인증·적합판정·밸리데이션 완료를 추정하지 않는다.
- 임상시험계획·정기 안전성정보·DSUR에서는 원자료 문서 종류, 시험번호·제품·제형·기간 및 실제 본문 절을 확인한다. 가이드 목차·예제·외국 관할 허가를 실제 시험 승인·국내 안전성 결론으로 바꾸지 않는다.
- 해외제조소·사전 검토에서도 신청인의 개인 정보·담당자 연락처·서명·동의·기관 판단은 직접 입력하거나 확인 대기로 남긴다.
- 카탈로그의 인쇄 첨부 안내와 민원인 안내서는 담당자의 적용 여부 검토를 돕는 자료이다. 전체 최신 법정 제출요건의 인증이나 개별 제품의 사실 근거가 아니다. 새로운 개정 자료를 오래된 서식에 조용히 섞지 않는다.
- 부족한 정보는 최대 2개의 질문으로 확인한다. 자료가 없으면 빈 값 또는 확인 필요로 남기며 실제 결과·기관 승인·전자 제출 성공·사용 빈도를 만들어 쓰지 않는다.
