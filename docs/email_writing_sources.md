# 이메일 작성 원칙과 자료 이용 조건

해외영업 이메일 작성은 받은 이메일과 사용자가 확인한 원자료를 근거로 수행한다. 공개 예문 이메일을 학습 데이터나 출력 템플릿으로 저장하지 않는다. `prompts/buyer_email.md`와 `prompts/buyer_email_review.md`의 문장은 프로젝트에서 직접 작성했다. 테스트의 회사명·거래조건도 합성 예시다.

| 참고 자료 | 이용 조건 확인 | 이 프로젝트에서 사용하는 범위 |
|---|---|---|
| [미국 GSA plainlanguage.gov](https://github.com/GSA/plainlanguage.gov/blob/main/LICENSE.md) | 저장소가 미국 공공영역 및 전 세계 CC0를 명시함 | 핵심 내용을 앞에 두고 명료하게 쓰는 일반 원칙만 참고함. 예문 본문은 복제하지 않음 |
| [영국 GOV.UK 이메일 작성 가이드](https://www.gov.uk/service-manual/design/sending-emails-and-text-messages) | 페이지 하단에 별도 표시가 없는 한 Open Government Licence v3.0 적용을 명시함 | 짧고 이해하기 쉬운 구조 원칙만 참고하며 문장·템플릿을 복제하지 않음. 이 링크로 출처를 표시함 |
| [대한민국 공공누리 이용 조건](https://www.kogl.or.kr/info/faqList.do?cPage=1&dataGroup=2&mstIdx=KOGL_005) | 자료별 유형이 다르며 제1유형은 출처 표시 조건으로 상업적 이용·변형 가능함 | 특정 국내 예문을 수집·복제하지 않음. 국내 비즈니스 존댓말·응대 흐름은 직접 작성함. 향후 개별 자료를 도입할 때 자료별 유형·출처·허용 범위를 확인함 |

실제 입력한 이메일과 회사 원자료의 저작권·기밀성·공유 권한은 해당 사용자·조직이 관리해야 한다. 본 기능은 공개 이메일 코퍼스를 임의 수집하거나 모델 재학습에 사용하지 않는다. 초안은 발송 전에 담당자가 수신인, 사실, 첨부, 거래조건을 확인한다.
