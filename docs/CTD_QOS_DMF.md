# 제조원 DMF → CTD 2.3.S 검토용 초안

`CTD 2.3.S`는 원료의약품의 품질요약(QOS) 부분임. [ICH M4Q(R1)](https://www.fda.gov/media/71581/download?attachment=)의 2.3.S.1~7은 Module 3의 3.2.S.1~7과 대응하며, 품질요약에 원자료에 없는 사실이나 정당화를 새로 넣어서는 안 됨. 이 기능은 제조원이 제공한 실제 DMF/3.2.S 원문을 해당 절에 **그대로 발췌·기입**하는 검토용 작업 초안을 만듦. 담당자의 요약·평가·제출 판단을 대신하지 않음.

## 사용

1. RA 작업실 `http://127.0.0.1:8504/`의 **DMF → CTD 2.3.S** 탭이나 외부 작업실 `/workspace`를 엶. 외부에서는 2.3.S DOCX/HWPX 양식(또는 합성 예제 양식)을 위 업로드 칸에 먼저 넣음. 로컬 탭은 양식이 없어도 근거가 있는 절의 프로젝트 예제 DOCX를 만듦.
2. 제조원 DMF 원문을 문서·표·PDF·텍스트·사진/스캔으로 첨부함. 사진/스캔의 OCR 또는 수동 전사 결과는 원본 페이지를 확인한 뒤 승인해야 사용됨. 암호·추출 제한을 우회하지 않음.
3. 선택 완제 품목, 원문에 **명시된** 원료명과 원료 제조원을 확인함. 같은 원료를 해당 완제에 실제로 사용하는 관계는 담당자가 원자료와 업무 기록으로 확인함. 서로 다른 원료 또는 제조원 자료를 한 초안에 합치지 않음.
4. 2.3.S.1~7 중 작성할 절을 고르고 근거·누락 미리보기를 확인함. 원문이 없는 절, 여러 값이 충돌하는 절, 분량/추출이 보류된 절은 자동 기입되지 않음.
5. 양식 사본과 별도 출처 JSON을 내려받음. 원본 SHA, 파일명, 페이지/시트, 출처 ID, 정확한 인용 범위, 원료·제조원 선언 근거, 미기입 절과 저장 후 검수 결과를 확인함.

자체 양식은 각 절의 입력칸에 `{{2.3.S.1}}`부터 `{{2.3.S.7}}`까지 **서로 다른 자리표시자**를 넣어 DOCX/HWPX로 올림. 양식에 있는 모든 자리표시자에 확인된 원문이 없으면 출력을 보류함. 원본은 덮어쓰지 않고 서식·표·자리표시자 위치를 저장 후 대조함.

이 작업은 기존 DMF의 원문을 옮기는 자동화라 실제 LLM 생성 요청은 0회이며 API 잔액이 없어도 읽을 수 있는 원자료는 처리함. 사진 자동 읽기에는 이미지 모델이 필요할 수 있고, 수동 전사는 담당자 확인 뒤 사용함. 2.3.S에 요구되는 해석·비교·정당화, DMF 비공개 부분 접근 권한, 최신 국내 신청별 서류 요건, eCTD 구조/제출 적합성은 별도 검토해야 함. 검증 파일 `samples/qos_dmf_synthetic.txt`, `samples/qos_dmf_demo_template.docx`는 프로젝트 합성 예제임.
