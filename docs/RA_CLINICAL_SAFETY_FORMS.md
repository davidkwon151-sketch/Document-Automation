## 공식 출처와 버전 확인

[별지23 공식 서식 페이지](https://www.law.go.kr/LSW/lsBylInfoP.do?bylSeq=18000755&lsiSeq=284019&efYd=20260305&directYn=Y)와 [PDF](https://www.law.go.kr/LSW/flDownload.do?flSeq=162105553), [별지32 공식 서식 페이지](https://law.go.kr/LSW/lsBylInfoP.do?bylSeq=18000773&lsiSeq=284019&efYd=20260305)와 [PDF](https://law.go.kr/LSW/flDownload.do?flSeq=162105611)를 사용함. 2026-10-03에 공식 PDF URL의 응답을 메모리에서 기존 원본과 비교해 두 파일 모두 HTTP 200·전체 바이트·SHA 일치를 확인함. 원본 파일을 교체하거나 새로 저장하지 않음. 웹 도구에서는 동적 서식 페이지 열기가 제한되어 [공식 제24조 연계 정보](https://law.go.kr/lsLinkCommonInfo.do?lspttninfSeq=116443)와 [공식 제30조 연계 정보](https://www.law.go.kr/LSW/lumLsLinkPop.do?chrClsCd=010202&lspttninfSeq=151450)에서 서식명·용도와 시행 2026-03-05를 함께 확인함.

별지23은 임상시험계획 승인/변경승인 신청서이며 별지32는 임상시험용의약품의 정기적인 최신 안전성정보 보고서임. 인쇄 개정일은 PDF 첫 쪽을 직접 관찰한 값임. 이 확인은 특정 스냅샷의 출처·용도 대조이며 현재 접수용 최신성·신청 자격·자료 면제·법적 적합성을 보장하지 않음. `current_version_verified`, `mandatory_requirements_verified`, `full_submission_ready`는 False로 유지함.

## 원문 데모와 직접 입력

두 양식 모두 `evals/ra_korean_sources.json`의 `ra-kr-hanmiflu-75`를 사용함. 공식 한미 제품 설명서에서 확인한 **한미플루 75mg** 원문 전체를 단일 alias로 연결함. 근거의 원문·출처 ID·PDF SHA·원페이지·문서 발행사 역할을 그대로 유지하며 새 제품 사실이나 회사 역할을 생성하지 않음. 제품명 복사는 해당 제품이 실제 시험약이라는 주장·임상시험 실시·국내 승인·안전성 판단이 아님. `제품명 성분명`이라는 슬롯 이름 때문에 성분명을 추가하지 않음.

별지23의 신청인·원개발사·제조원 7칸은 사용자 직접 입력임. 제품명·주성분·국내 허가 여부·제형·유효기간·임상시험 제목/단계·계획서 식별번호·첫 변경 행은 해당 내용의 원자료가 있을 때만 작성함. 기본 데모에서는 제품명 외 전부 비워 둠. 의약품 분류·함량 괄호·시험 용도·국내/다국가·기관·대상질환·날짜·서명·담당자·첨부자료는 미등록임. 기존 첫 쪽 설정은 뒤쪽을 작성하지 않음. 새 앞·뒤쪽 설정도 목적·투여 방법 2칸만 추가하며 나머지 요약정보는 자동 작성하지 않음.

별지32의 한국 임상 승인일·차수·승인받은 자 명칭/소재지·자료 마감·제출일 6칸은 사용자 직접 입력임. 원본 날짜·정수 검사도 유지함. 시험 제목·누적 투약 대상자 수·허가된 국가·안전성 종합 평가·위해성·결론은 실제 해당 시험의 자료가 필요함. 최초 국내외 승인/품목허가 날짜·보고 기간 분리 날짜·보고인·서명·담당자·DSUR 일체 첨부는 미등록임. 기존 첫 쪽 설정은 뒤쪽을 작성하지 않음. 새 앞·뒤쪽 설정도 서론·일련 목록/요약표 데이터 2칸만 추가하며 나머지 세부 내용 표는 미등록임. 일반 제품 설명서로 시험 대상자 수나 안전성 결론을 추정하지 않음.

## 근거 검수 단위·제품 역할 수정

별지32의 `누적 투약 임상시험 대상자 수`는 원래와 같이 무단위 정수만 출력함. 원본에 `명`이 인쇄되었다고 선언하지 않고 `validation.evidence_unit="명"`을 원자료 대조용으로 명시함. 유효한 고정 숫자 칸의 `12 [SID]`를 원자료의 같은 항목·범위의 `12명`과 대조할 수 있으며 입력이나 출처 원문을 변경하지 않음. `120`, `12mL`, 단위가 붙은 정수 입력, 비정수·음수·중간 인용은 차단함. 본문·제목·미선언 항목에는 이 검수 단위를 추정해서 붙이지 않고, 서로 다른 검수 단위의 합계·대소 관계도 허용하지 않음. 제품·성인/소아·함량 범위 검사는 그대로 적용함.

별지23 `시험약 제품명`과 별지32 `제품명 성분명`에는 명시적 `evidence_role="product_name"`을 추가함. 알려진 출처 ID라는 이유만으로 다른 제품의 원문을 해당 명칭의 근거로 인정하지 않음. 선택 제품·전체 명칭의 원문과 출처 문맥을 대조하고, 입력 역할의 미지 값·잘못된 타입·같은 값 이름의 역할 충돌을 차단함. 데모 alias는 동일한 한미플루 제품명 원문과 출처를 사용하며 성분명·시험약 지위를 생성하지 않음.

변경 전 두 프로파일과 카탈로그는 [수정 전 JSON·SHA 스냅샷](../outputs/ra-clinical-safety/evidence-unit-fix/before.json)에 보존함. 위 SHA 표는 수정 후 바인딩이며 앞선 `qa.json`의 프로파일 SHA와 불변 판정은 **최초 연결 당시의 역사적 스냅샷**임. 새 변경 감사와 집중 검증은 [수정 감사](../outputs/ra-clinical-safety/evidence-unit-fix/audit.json) 및 [집중 테스트 XML](../outputs/ra-clinical-safety/evidence-unit-fix/pytest-final.xml)에서 분리함. 이 수정은 근거·입력 경계 보강이며 임상시험 또는 안전성 보고의 적합성 인증이 아님.

수정 후 집중 회귀 **500개 통과(202.12초)**이며 신규 단위/역할 회귀는 58개임. RA32 한 칸에 무단위 가짜 값 `12`를 저장한 2쪽 PDF는 독립 출력 검수 통과함. 첫 쪽을 PDFium으로 새 렌더하고 직접 시각 확인해 해당 값이 원칸 안에 보이며 새 잘림·겹침을 발견하지 못함. 뒷쪽은 독립 원본 보존 검사 범위이며 이번 새 직접 시각 확인 분모에 넣지 않음. 실제 API·모델 응답·사람 KPI는 0임.
