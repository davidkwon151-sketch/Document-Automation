# RA 공개 제출 서식 출처

확인일은 2026-10-03 한국시간이며, 카탈로그의 `checked_at`에는 실제 확인 UTC 시각을 저장함. 공식 원본 34개를 로컬에 보존하고 동일 서식의 PDF/HWP를 묶어 18개 대표 문서로 등록함. 대표 문서 18개 모두 SHA-256이 서로 다르며 다운로드 캐시의 해시를 다시 확인함.

## 출처와 버전

[국가법령정보센터의 의약품 등의 안전에 관한 규칙](https://law.go.kr/LSW/lsInfoP.do?ancYnChk=0&lsId=011794)의 현행 본문은 시행 2026-03-05, 총리령 제2100호임. 해당 버전의 공식 별지 목록과 다운로드 버튼에서 관찰한 파일 ID로 16개 별지의 PDF·HWP를 확보함. 법령 본문 시행일과 개별 서식에 인쇄된 개정일은 서로 다른 메타데이터로 저장함.

개별 서식의 `source_page`, 관찰된 직접 `source_url`, 원본 파일명·형식·크기·SHA-256, PDF 페이지 수, 원문 개정일은 [ra_catalog.json](../templates/ra_catalog.json)에 저장함. PDF가 대표 문서이며 같은 별지의 실제 HWP 원본은 `alternative_originals`로 함께 보존함. 바이너리 HWP를 HWPX로 표시하거나 변환 완료로 취급하지 않음.

추가로 다음 두 원본을 수집함.

- [식약처 의약품 GMP 영문증명 개선 알림](https://www.mfds.go.kr/brd/m_522/view.do?seq=33252)의 첨부 3번 영문 증명 신청서 HWP: 게시일 2019-05-07인 과거 원본임. 현재 전자신청 양식이나 제출요건을 대신한다고 판단하지 않음.
- [국가법령정보센터 위해성 관리 계획 개요 원본 PDF](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200201&flNm=%5B%EB%B3%84%ED%91%9C+9%EC%9D%983%5D+%EC%9C%84%ED%95%B4%EC%84%B1+%EA%B4%80%EB%A6%AC+%EA%B3%84%ED%9A%8D+%EA%B0%9C%EC%9A%94%28%EC%A0%9C7%EC%A1%B0%EC%9D%982+%EA%B4%80%EB%A0%A8%29&flSeq=144915301): 관찰 파일 ID와 실제 PDF 내용·해시를 확인했으나 최신 고시와의 소속 관계 및 시행일은 미확인임. [품목허가·신고·심사 규정](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000284794)은 최신성 추가 확인을 위한 별도 참고 출처로 기록함.

안내서, 완성된 CTD 예시, 작성된 기업 보고서를 빈 제출 서식으로 등록하지 않음. 비공개 제약기업 CTD나 회사 내부 양식을 확보한 범위는 없음.

## 이용과 검증 범위

`templates.ra.RA_WORKFLOWS`의 고정 키는 `product_approval`, `variation`, `clinical_trial`, `dmf`, `gmp`, `manufacturing_import`, `safety_management`임. `load_ra_catalog()`, `list_ra_templates(workflow=None)`, `download_ra_template(entry, directory=...)`를 제공함. 실제 원본 폴더는 `data/public_templates/ra/`임.

다운로드는 카탈로그의 관찰된 공식 HTTPS URL·호스트·파일명·해시와 일치하는 요청만 허용함. HTML 로그인 화면을 문서로 저장하는 경우, 형식 불일치, 변경된 캐시, 경로 이탈을 거부하며 공유 다운로드 함수의 용량 제한을 적용함. 기존 원본은 변경된 파일로 덮어쓰지 않음.

서식 4·8·23의 PDF 입력 프로필과 실제 샘플 작성 검증은 별도의 프로필 검증 결과로 관리함. 카탈로그 전체 18종에 대한 기입 완료, 현행 법적 제출 적합성, 필수 첨부자료 충족은 인증하지 않으며 관련 플래그는 모두 `false`임. 주민등록번호·담당자·서명·동의 등 직접 입력 항목을 출처 없이 생성하지 않음.

원본 재배포 허용 조건은 미평가임. 공개 다운로드 가능하다는 사실만으로 재배포 허가를 추정하지 않으며 로컬 원본 폴더는 Git 제외 대상임. 원본 저작권·출처 메타데이터를 보존함.

검증 명령: `.venv\Scripts\python.exe -X utf8 -m pytest tests/test_ra_catalog.py -q` — 오프라인 테스트 21개 통과함. 실제 대표 원본의 해시·크기 재검증 목록은 `outputs/ra_source_inventory.json`에 기록함.
