## 한정된 RA 파일럿 준비도 55%의 계산

## 앞으로 필요한 시간

아래 개발 시간은 현재처럼 병렬 에이전트가 작업하고 사용자가 결정을 제공한다는 가정의 **집중 작업 경과시간**임. 에이전트 4개 각각의 시간을 합친 인시와 다름. 실제 모델 실행 시간을 측정한 적이 없어 API 지연·한도·모델별 오류 수정의 범위는 계획 추정임.

| 한정 파일럿의 남은 작업 | 집중 작업시간 범위 | 완료를 가르는 조건 |
|---|---:|---|
| 사용자 키/모델 설정과 실제 생성·임베딩·의미 검수 smoke 확인 | 1–2시간 | 키·모델 접근·사용 조건 준비, 실제 응답을 기록할 수 있어야 함 |
| 실제 20–30문서 작성과 오류 분석·한두 차례 프롬프트/검색 조정 | 4–10시간 | 원문 복사 대신 실제 모델 초안을 평가하며 실패/미평가를 보존함 |
| 사용자 실제 입력·수정·재생성·경고 해결·다운로드/복원 확인 | 3–6시간 | 대표 작업이 브라우저에서 끝까지 완료됨. 개인정보·서명은 사용자 직접 입력 |
| 파일럿 설치·접근/보관·백업/복구·비용/시간 관찰과 운영 안내 | 2–6시간 | 실제 조직의 로컬 운영 조건을 확인함. 조직 전체 배포는 제외 |
| **개발·자동화 합계** | **10–24시간** | **외부 준비와 새 큰 결함이 없다는 조건** |

이외에 RA 전문가의 선택 원문·현행성·조건 검토 **4–10인시**, 실제 사용자 20–30문서의 작성/수정·기준선 비교 **10–25인시**를 별도 계획함. 여러 사람이 병행하면 이 인시 합계가 그대로 경과시간이 되지 않음. 담당자의 숙련도·문서 길이·첨부 범위에 따라 달라짐. 이 시간은 관측한 사용시간이 아님.

따라서 “앞으로 몇 시간”에 대한 한정된 답은 **이번 검증 산출물은 완료돼 남은 0시간**, 이어 **한정 파일럿 준비 약 10–24시간의 집중 개발/검증**임. 실제 실무 문서를 모아 수정률·시간·반려를 관찰하는 달력 계획은 약 **2–4주**임. 키 제공·전문가 참여·사용자 업무 일정은 현재 미확정이며 그 대기 시간을 여기에 더해야 함. API·사람 평가 없이 자동화 작업만 계속한다고 파일럿의 미평가 조건이 충족되지는 않음.

수정 비율을 얼마나 줄여야 완료인지의 목표값은 아직 없음. 실제 첫 AI 초안과 최종본을 비교하고 수작업 기준선·검토 품질과 함께 목표를 정해야 효과 완료율을 계산할 수 있음. 여러 번의 AI 내부 수정을 사용자 수정 감소로 계산하지 않음.

반복 회귀 1회가 약 7–10분이라는 관찰은 현재 고정 검증 산출물의 마감 시간을 추정하는 데 사용함. 모델 정확도·새 양식 호환·사용자 수정률이 자동으로 같은 속도로 개선된다는 추론은 하지 않음. 직전 실패·중단과 후속 수정은 별도 기록에 남아 있으므로 순조로운 실행만 골라 전체 개발속도를 과장하지 않음.

## 모든 회사·기관 목표의 완료율을 계산할 수 없는 이유

- 현재 기업집단은 자산 상위 30개 기준의 공개 원본 일부이며 회사·계열사 내부 양식의 전수 목록이 아님. 매출 상위 1000개는 FY2024 인천 소재 38기업 부분 목록이며 최신 전국 1000개 전수 원본이 없음.
- 정부 registry **667기관**과 공식 홈페이지 링크 **637개**는 기관 목록임. 고유 원본 **201개**와 실제 출처 기관 **36개**도 전체 양식의 분모가 아님. [기존 확보 범위](VALIDATION.md)
- 수집 원본에는 완성 보고서·정책·안내·미분류 후보·보호 자료가 섞임. 수집·읽기·선택 기입·전체 업무 적합성·프로그램 표시를 서로 다른 상태로 관리함.
- 임의 양식은 구조·보호·버전·사용 프로그램과 사업장별 업무 규칙이 계속 달라짐. 비공개 원본은 사용자의 권한과 제공이 필요하며 접근 제한을 우회하지 않음.
- “사람 수정 최소”는 실제 사용자·업무·품질 기준에 종속됨. 현재 실제 수정 표본 0건이고 허용 수정률·심각 오류·반려 목표가 미정이어서 최종 효과 완료율을 계산할 수 없음.

예측 가능한 다음 단계는 “모든 기업” 대신 조직·업무·양식·버전·뷰어·평가 문서 수를 고정한 출시 범위를 정하는 것임. 실제 원본 확보·품질 목표·보호/복잡 구조 비율과 한정 파일럿 결과가 정해진 뒤 다음 확장 단계의 시간을 산정해야 함.
