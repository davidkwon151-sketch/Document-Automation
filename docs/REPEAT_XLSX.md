# XLSX 반복 입력 행

`templates/repeat_xlsx.py`는 원본 XLSX의 ZIP 부품을 메모리에서 읽고 변경 부품만 반환함. `openpyxl.insert_rows()` 또는 통합문서 전체 저장으로 그림·서식·관계를 재작성하지 않음. Tokenizer로 수식의 참조 토큰을 구분하고 원문 위치·공백을 따로 보존함. 삽입 참조 이동은 직접 계산하며, 상대 복사는 각 참조 토큰에만 Translator를 적용함.

## 호출 계약

```python
inventory(parts: dict[str, bytes]) -> list[dict]
transform(parts: dict[str, bytes], plan: dict) -> dict[str, bytes | None]

plan = {
    "table_id": "xlsx:xl/worksheets/sheet1.xml",
    "row": 6,
    "count": 3,
}
```

`row`는 실제 Excel의 1부터 시작하는 행 번호임. 빈 번호가 생략된 시트에서도 XML에 존재하는 행을 그 번호로 선택함. `count`는 원형을 포함한 최종 수이며 1~200만 허용함. `inventory.row_count`는 존재하는 XML 행 수, `max_row`는 마지막 실제 행 번호임. `rows`는 원문 열 값·확장 후보 여부·보류 이유를 포함함. 후보 탐지가 업무 역할이나 필수 제출 항목을 확정하지는 않음.

원형 행 뒤에 `count-1`개를 삽입하고 뒤의 원래 행을 이동함. `count=1`은 변경 부품이 없는 작업임. 파일 입출력·원자적 저장·원본 SHA 연결·독립 검수는 호출자가 맡음. `None`은 계산 체인 부품의 명시적 삭제에만 사용함.

## 참조 이동과 복사

삽입 기준 행을 `r`, 추가 수를 `d`라고 하면 해당 시트의 원래 셀 주소 중 `r`보다 큰 행은 `d`만큼 이동함. `$`가 있는 절대 참조도 참조 대상 원래 셀의 이동에 따라 바뀜. 원형 수식을 이 상태로 먼저 갱신한 뒤 복제 행으로 상대 참조만 복사함. 다른 시트의 상대 참조도 Excel의 복사 의미에 따라 이동하지만 절대 참조는 복사 단계에서 유지함.

예를 들어 2행을 원형 포함 3행으로 확장하면 다음과 같이 처리함.

| 위치 | 수식 |
| --- | --- |
| 원본 F2 | `B2*$G$5+Other!A2` |
| 준비본 F2 | `B2*$G$7+Other!A2` |
| 준비본 F3 | `B3*$G$7+Other!A3` |
| 준비본 F4 | `B4*$G$7+Other!A4` |

수식 문자열 안의 주소처럼 보이는 글자는 바꾸지 않으며 원문 공백을 보존함. 시트 이름 비교는 Excel처럼 대소문자를 구분하지 않음. 이름 참조와 지원하는 표의 구조화 참조는 문자열을 유지하고 그 이름·표의 실제 범위를 이동함.

범위가 원형 행을 포함하고 끝 행이 원형과 같으면 끝을 새 반복 행까지 늘림. 원형 단일 셀을 가리키는 일반 수식 참조는 그대로 유지함. 따라서 아래 합계 행의 `SUM(B2:B2)`는 `SUM(B2:B4)`가 됨. 입력 제한·조건부 서식의 단일 원형 셀 적용 범위는 새 반복 행까지 확장함. 가로 병합은 이 범위 확대의 예외로, 각 행의 원래 병합을 별도로 복제함.

범위 끝이 Excel 최대 행 1,048,576이면 끝을 그 행에 유지함. 범위 시작은 정상 이동함. 실제 최대 행에 존재하는 XML 행이나 단일 최대 행 참조를 밖으로 밀어내는 작업은 차단함. 복사한 수식이 최대 행을 넘는 경우에도 값을 자르거나 참조를 임의 수정하지 않음.

## 유지·변경 범위

- 원형의 입력값·자리표시자·행 높이·숨김·그룹·셀 스타일·숫자 형식을 유지함. 수식 참조 이동과 계산 캐시 제거는 명시된 예외임. 고정 순번을 자동 재번호로 바꾸지 않음.
- 가로 병합을 행별 복제하고 뒤쪽 병합 주소를 이동함. 원형을 가로지르는 세로 병합은 보류함.
- 일반 및 x14 입력 제한의 적용 범위와 수식, 조건부 서식, 정의 이름, 인쇄 범위, 필터·정렬·표 범위, 표 계산 열 수식을 이동함. 선택 옵션·표시·UID·조건 속성은 유지함. x14에서는 알려진 `dataValidation`의 `xm:sqref`와 `xm:f`만 이동함.
- 창 위치·선택 셀·행 나누기·아래쪽 그림 앵커를 이동함. 고정 창의 경계 안에 삽입되는 경우만 고정 행 수를 늘림. 원형 행을 가로지르는 그림은 보류함. 위쪽 단일 셀 앵커와 절대 위치 그림은 원본의 기본·명시 행 높이, 숨김 행, 오프셋·그림 높이를 EMU로 대조하여 원형 행 위 경계 안에 완전히 들어올 때만 유지함. 배치를 증명할 수 없거나 삽입 영역과 겹치면 보류함.
- 원형 행의 하이퍼링크는 같은 관계·목적지를 유지하며 복제함. 다른 시트의 내부 하이퍼링크가 이동한 셀을 가리키면 목적지도 갱신함.
- VML 댓글은 댓글 도형과 연결 행이 원형보다 완전히 위에 있어 이동할 필요가 없는 경우에만 원본 부품 그대로 허용함. 댓글 복제·이동이 필요한 경우는 보류함.
- 영향을 받는 차트의 A1 범위를 갱신하고 그 차트의 숫자·문자 캐시를 제거함. 스타일·테마·그림·미디어·원래 관계 등 비대상 부품은 그대로 유지함.

수식 셀의 오래된 캐시는 비보호 시트에서 제거하고 `fullCalcOnLoad=1`, `forceFullCalc=1`을 요청함. `calcMode` 등 원래 계산 설정은 유지함. 영향 없는 보호 시트는 수식 캐시까지 원본 바이트를 유지함. 보호 시트의 수식·내부 링크·표 수식 등을 바꿔야 하면 그 계획은 차단함.

기존 `calcChain`은 부품과 해당 관계·콘텐츠 유형 선언을 함께 제거함. 다른 관계를 계산 체인으로 위장한 원본은 거부함. 재계산 요청이나 수식 텍스트 검사를 실제 Excel 재계산 완료로 표시하지 않음.

## 명시적으로 보류하는 구조

전자 서명, 활성 통합문서 보호, 대상 시트 보호, 매크로·외부 통합문서·피벗·쿼리 의존성, R1C1·반복 계산, 공유·배열·데이터 테이블 수식, 간접·동적 참조 수식, 알 수 없는 확장 주소·행 식별자, 세로 병합 경계와 이동이 필요한 댓글은 보류함. 영향 없는 다른 보호 시트가 있다는 이유만으로 전체 통합문서를 차단하지 않음.

원문 업무 의미를 판단하기 어려운 고정 순번·합계·표 머리 행도 자동 반복하지 않음. 일반 텍스트·선택·숫자 입력의 직접 입력 권한과 규칙 승계는 준비본의 위치별 프로파일에서 별도로 검사함.

## 위치·원본 규칙·새 양식 매핑

공통 `repeat_profile()`과 `inherit_repeat_rules()`가 XLSX의 실제 셀 주소별 입력을 연결함. 원형 수식 셀은 입력 대상으로 만들지 않으며 빈 물리 셀과 자리표시자는 행마다 고유 값 이름을 가짐. 원본 SHA·직접 입력·필수·길이·숫자·선택 목록과 항목 관계를 다시 확인함. 행 안 관계는 행별로 복제하고 행 밖 관계는 주소 이동에 맞추어 연결함. 혼합 관계를 명확히 승계할 수 없으면 보류함.

원래 `{{자리표시자}}`의 필수 조건과 native 목록은 AI 매핑으로 완화하지 않음. 새 매핑 힌트에서는 `(예시)`·`Example`과 고정 순번 데이터 행을 머리글 후보에서 제외하고 앞쪽 머리글 문맥을 모델에 함께 제공함. 임시 항목명은 사용자 확인과 필수 조건 정의를 대신하지 않음. 원본 또는 1행 준비본과 반복 매핑 캐시는 별도로 보관함.

RA 비용은 시험용 합성 값이며 약품의 실제 시험 내역·규제 비용이 아님. XLSX 저장본의 계산 캐시는 비워 두므로 운영 파서는 비용 샘플의 수치를 `uncalculated_formula`로 보류함. 실제 Excel 재계산이 성공해도 계산값을 원본 ZIP에 저장한 것으로 표시하지 않음.

계산 비교는 15칸과 입력 변경·복원 1건임. 선택 시트에서 나온 PDF 12개/64쪽을 렌더했으며 비교 몽타주 8개와 선택 기입 영역 7쪽을 개별 확대 확인함. PNG 고유 해시는 45개임. 짧은 신규 선택값의 잘림·겹침은 발견하지 않았음.

**인쇄 제한:** 두 공개 양식 모두 원본부터 열 방향으로 여러 페이지에 분할되어 안내문·넓은 제목이 페이지 경계에서 나뉨. 인도 양식은 늘어난 행이 다음 페이지로 이어져 페이지가 증가함. 원본 배율·폰트·인쇄 범위를 임의로 고치지 않았으므로 최종 PDF 제출용 페이지 구성은 별도 확인해야 함. 이 결과를 장문 입력·원본의 모든 시트/항목·오탈자 전수·완성 제출 문서 인증으로 표시하지 않음.
