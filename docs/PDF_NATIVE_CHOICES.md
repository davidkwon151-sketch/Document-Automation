# PDF 선택 목록 보강 — 2026-10-03

공개 RA 의뢰 양식을 검증하면서 발견한 PDF 선택 입력의 호환성 공백을 보강함. 서브에이전트 3개가 원본 조사·작성기·독립 검수기를 나누고 화면·확인 매핑 재사용·초안 작성 연결을 통합함. 실제 모델 학습 또는 기업별 모든 양식 검증을 뜻하지 않음.

## 작성 계약

- 원본 `/Opt`의 저장 코드와 표시 문구를 구분함. 닫힌 단일 선택은 정확한 코드만 허용함.
- 원본 Combo+Edit 플래그가 있으면 기존 옵션과 사용자의 한 줄 직접 입력을 허용함. 원본 옵션이 없는 직접 입력 콤보도 권한을 바꾸지 않고 작성함.
- 다중 선택은 문자열 값 `"[\"AUTH\",\"RENEW\"]"` 형태로 전달함. 저장 순서는 원본 옵션 순서이며 `/V` 배열·`/I` 인덱스와 표시 강조를 함께 대조함. 의미가 같은 표시 이름으로 저장 코드를 추정하지 않음.
- 빈 UI 입력은 원본 선택값을 유지함. 첫 옵션·동의·지원 자격·승인을 자동 선택하지 않음. 빈 JSON 배열은 선택 해제 명령으로 처리하지 않음.
- 실제 공백 저장 코드/공백 표시 옵션은 원본 증거와 인덱스에 유지하고 선택 UI에서 제외함. `Select option` 코드에 `No` 표시가 연결되어 있으면 그 실제 값을 사용함.
- 같은 항목명에 단일·다중·직접 입력 권한 또는 서로 다른 옵션이 섞인 매핑은 저장하지 않음. 원본 해시가 같은 구형 캐시의 빠진 선택 메타데이터는 원본에서 복구하되 상충하는 메타데이터는 거부함. 개인 값·답변은 학습 캐시에 저장하지 않음.

작성기는 원본 옵션·플래그·배경·색·글꼴 자원을 유지하면서 새로운 표시 스트림을 작성함. 한글 표시와 영역 넘침을 검사하고 내용이 안 들어가면 잘라내지 않음. 목록을 스크롤해 모든 선택값이 보일 수 있는 범위만 허용함. 원래 목록 자체를 늘리거나 글꼴 크기를 몰래 낮추지 않음.

## 이중 검수

저장 후 검수기는 원본 PDF의 옵션·부모 연결·페이지·주석 순서·좌표를 다시 읽음. 작성기의 값 해석을 재사용하지 않고 선택 코드·인덱스·실제 표시 문구·강조 위치·표시 경계와 비선택 값을 검사함. 원래 Rect는 엄격하게 대조하고 Rect에서 계산한 폭/높이의 직렬화 부동소수 오차만 0.000001pt까지 허용함.

회귀에는 잘못된 코드·표시 문구·인덱스·권한·옵션·원위치·배경·자원·표시 강조 변경과 잘림을 포함함. 화면은 다중 선택을 비어 있는 상태로 시작하며 저장한 JSON 선택을 검증해 복원함. 잘못된 복원값은 사용자가 확인하고 비우기 전 작성하지 않음. mock 초안→검수→다운로드 통합은 직접 입력 선택값을 출처와 함께 잠그고 수동 변조를 차단함.

읽기 전용 최종 감사에서 기본 항목명(제목·요약·본문)에 매핑한 직접 입력칸의 UI 누락과 같은 코드/반대 표시 문구의 미러 매핑을 발견함. 모든 직접 입력칸을 표시하고 코드·표시 대응 전체를 매핑 계약에 넣어 수정함. 선택 전 빈 값, 같은 대응의 정상 재사용, 서로 다른 의미의 합병 거부를 5개 회귀로 확인함. 수정 전 중단한 전체 테스트는 `outputs/pdf-choice-contract/interrupted-audit.json`에 보존함.

## 실제 원본과 합성 시험의 구분

[공식 원본 조사](PDF_CHOICE_SOURCES.md)와 `evals/pdf_choice_sources.json`에 Thermo Fisher/Gibco·GSA/OPM·NMBI의 고유 원본 3개, 전체 21쪽, canonical 항목 281개/형식 있는 필드 279개, 실제 선택 목록 20개를 기록함. 실제 자료의 선택 목록은 모두 닫힌 단일 선택임. 직접 입력 콤보·다중 선택은 합성 원본의 회귀·표시 검사 범위이며 실제 공개 양식에서 확보했다고 표시하지 않음.

Thermo는 이전 RA 단계에서 확보한 동일 SHA 원본을 재사용함. 선택 실물 기입은 합성 사용자 선택 3칸에 한정하며 GSA의 인증·권한 보호 양식은 보류함. 실제 주문·임상 판단·취업 자격 선언 또는 기관 제출을 실행하지 않음. PDFium 렌더와 독립 구조·표시 검사 결과를 실제 Acrobat 편집 검증으로 확대하지 않음.

최종 실행별 테스트·RA 회귀·해시 근거는 `outputs/pdf-choice-contract/`에, 최종 선택칸 출력·전체 페이지 이미지·검수 결과는 `outputs/pdf-choice-public-final/`에 보존함. 수정 전의 `outputs/pdf-choice-public-qa/`와 이전 [RA 교차 검증](RA_CROSS_COMPANY_VALIDATION.md)의 결과는 역사 기록으로 유지함.

실물 부분 기입은 2개 출력/3개 선택칸이 독립 검수와 표시 확인을 통과하고 보호 원본 1개는 보류함. 원본 21쪽·작성본 12쪽을 PDFium으로 순차 렌더하고 몽타주 2개와 선택 영역 3개를 확대 대조함. 합성 양식은 7개/7출력쪽의 독립 검수·직접 시각 확인 범위이며 원본 포함 렌더는 14쪽임. root가 다시 확인한 합성 4쪽은 이 7쪽에 포함되며 별도로 더하지 않음.

RA 재회귀는 35계획 중 30기입 통과·5보호 보류, 전체 선택 원문·출처 74/74·수치 포함 항목 61/61을 확인함. 최종 30개 출력/96쪽의 SHA가 이전 시각 QA의 PDF와 바이트까지 동일함을 대조하여 기존 시각 근거를 재사용함. 새 RA 96쪽을 렌더한 것으로 집계하지 않음. 새 공식 선택칸 33쪽 렌더와 RA의 기존 시각 근거 재사용은 서로 다른 범위임.

## 남은 확인

최종 전체 pytest는 **2,740 passed·1 skipped·2 warnings·435.02초**임. 코드·프롬프트·프로파일·manifest·글꼴·설정 254대상의 전후 SHA 불변을 확인했고 신규132회귀를 포함함. 집중216개도 통과함. skip은 기존 에리우스 원본의 일반 텍스트 추출 권한 제한이며 두 경고는 Starlette/httpx deprecation과 openpyxl x14 확장 읽기 경고임. 출력을 openpyxl로 다시 저장하지 않고 원본 XML 부품 보존을 대조함.

mock 기대 상태15/15와 전문 업무 규칙24/24는 이전 기준 대비 하락이 없었고 실제 EMA 원문을 바탕으로 한 선정 정상17/17·변조92/92를 확인함. 의미·모델 정확도 또는 사용자의 실제 수정 비율을 측정한 수치가 아님. 최종 근거 묶음은 `outputs/pdf-choice-contract/verification.json`임.

원본 권한이 있는 서명/사용권 양식의 안전한 작성, XFA·특수 플래그·모호한 원본 옵션, 실제 PDF 편집기의 재편집·전자 제출 요건은 추가 확인 대상임. 인용 ID 문법과 같은 선택 코드(`[S1]` 등)는 직접 어댑터의 해석과 전체 초안/출처 경로의 호환 범위를 구분함. 현재 전체 경로에서 이런 예약 구문을 일반 코드처럼 작성할 수 있다고 보장하지 않음.

실제 API 모델 응답과 사람 최종 수정 기록은 아직 없으므로 모델 정확도·초안 수정 비율·시간 절감의 개선 수치를 제시하지 않음. 이 단계는 선택값의 잘못된 기입과 표시 오류를 줄이는 구현·회귀·실물 일부 검증임.
